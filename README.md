# Healthcare Analytics: Doctor Visits Analysis Using Python

## 📌 Project Overview

This project focuses on analyzing healthcare data to understand patterns in doctor visits and healthcare utilization.

The dataset contains information about patients, including age, gender, income, illness, health status, healthcare coverage, and chronic health conditions.

The project uses Python-based data analytics techniques to clean, prepare, analyze, and visualize the healthcare dataset.

---

## 🎯 Objectives

- Analyze doctor visit patterns in the healthcare dataset.
- Understand the demographic characteristics of patients.
- Analyze the distribution of age, gender, illness, health status, and doctor visits.
- Study the relationship between doctor visits and patient-related factors.
- Examine relationships between numerical healthcare variables.
- Identify patterns using statistical analysis and data visualization.
- Present meaningful insights from the healthcare dataset.

---

## 📂 Dataset

The project uses a healthcare dataset containing information related to doctor visits and patient characteristics.

The dataset includes variables such as:

- `visits` – Number of doctor visits
- `gender` – Gender of the patient
- `age` – Age of the patient
- `income` – Patient income
- `illness` – Number/level of illnesses
- `reduced` – Reduced activity due to health
- `health` – Health status
- `private` – Private healthcare coverage
- `freepoor` – Free healthcare indicator for poor patients
- `freerepat` – Free healthcare indicator for repatriated patients
- `nchronic` – New chronic condition
- `lchronic` – Long-term chronic condition
- `id` – Patient identification value

## ▶️ How to Run the Project

### Using Google Colab

1. Open the `.ipynb` file in Google Colab.
2. Upload the healthcare CSV dataset if required.
3. Make sure the CSV filename matches the filename used in the notebook.
4. Run the notebook cells sequentially.
5. View the statistical analysis and visualizations generated by the notebook.

### Using Jupyter Notebook

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the `.ipynb` file using Jupyter Notebook or JupyterLab.
4. Place the CSV dataset in the same project directory.
5. Run the notebook cells sequentially.
